# Typography

Configure the sizes, alignments, and other properties of texts.

## Headings

The following elements are available:

- `<h1>` to `<h6>`
- `.h1` to `.h6` classes
- `is-font-size-1` to `is-font-size-7` classes

:::info

To see the available sizes, visit the [customize font sizes documentation](../customize/fontsize).

:::

### Examples

<PreviewElement>
  <h1>Title 1</h1>
  <h2>Title 2</h2>
  <div className="h3">Title 3</div>
  <div className="is-font-size-4">Title 4</div>
</PreviewElement>
```html
<h1>Title 1</h1>
<h2>Title 2</h2>
<div className="h3">Title 3</div>
<div className="is-font-size-4">Title 4</div>
```
