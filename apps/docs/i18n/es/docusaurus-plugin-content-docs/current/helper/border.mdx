# Border

Controla de forma rápida y flexible los estilos de borde de tus elementos.

## Radius

Redondea las esquinas de tus elementos con las utilidades `is-rounded-{value}`.
Estas clases te permiten aplicar distintos niveles de curvatura, desde esquinas sutiles hasta círculos completos.

                Lorem ipsum
              </div>
            </PreviewElement>
          </div>
        </td>
      </tr>
    ))}
  </tbody>
</table>

:::tip

💡 Consejo: Usa `is-rounded` para elementos circulares como avatares o íconos.

:::
