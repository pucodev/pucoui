# Imagen

Configura tamaños y aspect-ratio de tus imágenes

## Uso básico

<PreviewElement>
  <ImageExample />
</PreviewElement>

<CodeBlock language="html">{ImageExampleCode}</CodeBlock>

## Redondeado

Para redondear las imágenes puedes usar el helper de dimensiones para ello usa las clases `is-rounded-*`

Donde `*` puede ser del 0 al 6

En caso se requiera que este completamente redondeado puedes usar la clase `is-rounded`

<Tabs>
  <TabItem value="preview" label="Preview">
    <PreviewElement>
      <ImageRounded />
    </PreviewElement>
  </TabItem>

  </TabItem>
</Tabs>

## Fallback

  <TabItem value="preview" label="Preview">

  </TabItem>

  <TabItem value="code" label="Code">

  </TabItem>

## Relación de aspecto

Usa estas clases para configurar la relación de aspecto de una imágen, estas clases son responsivas es decir siempre van a mantener la relación de aspecto aunque la pantalla sea pequeña o grande

<table>
  <thead>
    <tr>
      <th>Clase</th>
      <th>Tamaño</th>
      <th>Preview</th>
    </tr>
  </thead>

  <tbody>
    {imageAspectRatios.map(ar => (
      <tr>
        <td><CodeBlock>is-{ar[0]}by{ar[1]}</CodeBlock></td>
        <td>
          {ar[0]} / {ar[1]}
        </td>
        <td>
          <PreviewElement>
            <ImageBase image={4} ratio={ar.join(' ')} style={{maxWidth: '200px'}} />
          </PreviewElement>
        </td>
      </tr>
    ))}

  </tbody>
</table>
