# Checkbox

Componente de entrada que permite al usuario seleccionar o deseleccionar una opción binaria, como verdadero/falso o activado/desactivado.

## Uso básico

Para implementar checkbox usar el elemento `input` y tipo `checkbox` además se debe utilizar la clase `field` y `checkbox` como clase contenedora.
