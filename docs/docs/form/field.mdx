# Field

Usa el componente Field para componer un elemento de formulario con una etiqueta, texto de ayuda y mensaje de error

## Estructura

- `.field`: Elemento contenedor
  - `.label`: Etiqueta label para la entrada de formulario
  - `<input>, <textarea>, <select>`: Elemento de formulario
  - `.help`: Texto de ayuda

## Colores

Para agregar color al field puedes usar las clases

| Clase                             | Color | Variable                                   |
| --------------------------------- | ----- | ------------------------------------------ |
| <CodeBlock>is-valid</CodeBlock>   | Verde | <CodeBlock>--pui-color-success</CodeBlock> |
| <CodeBlock>is-invalid</CodeBlock> | Rojo  | <CodeBlock>--pui-color-error</CodeBlock>   |

:::info
Para más información de los valores de los colores visitar la [documentación de personalización de colores](../customize/color)
:::
