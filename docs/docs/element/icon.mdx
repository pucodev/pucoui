# Icons

Add icons to your project to improve the usability and aesthetics of your application.

For iconography, it is recommended to use [iconify](https://iconify.design/).

## Iconify

### Installation

Iconify has several installation methods: _via CSS, HTML, on-demand_.

We recommend using the **on-demand** version. To learn more about the advantages and disadvantages of using this method, visit their [documentation](https://iconify.design/docs/usage/#icons-on-demand).

#### On-demand

Add the following script to your HTML. For more information, visit their [documentation](https://iconify.design/docs/iconify-icon/#registering-the-web-component).

```html
<script src="https://cdn.jsdelivr.net/npm/iconify-icon@3.0.0/dist/iconify-icon.min.js"></script>
```
