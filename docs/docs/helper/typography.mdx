# Textos

Configura los tamaños, alineaciones y otras propiedades de los textos

## Headings

Se tienen disponible los siguientes elementos:

- `<h1>` al `<h7>`
- Clase de `.h1` al `.h7`
- Clase de `is-font-size-1` al `is-font-size-7`

:::info

Para ver los tamaños disponibles visitar la [documentacion de personalizar textos](../customize/fontsize)

:::

### Ejemplos

<PreviewElement>
  <h1>Título 1</h1>
  <h2>Título 2</h2>
  <div className="h3">Título 3</div>
  <div className="is-font-size-4">Título 4</div>
</PreviewElement>
```html
<h1>Título 1</h1>
<h2>Título 2</h2>
<div className="h3">Título 3</div>
<div className="is-font-size-4">Título 4</div>
```
