# Flex

export function ItemDefault({ color, width, minHeight, content }) {
  return (
    <div
      className={`is-bg-${color || 'primary'} p-3 is-rounded-2`}
      style={{ width: width || 'fit-content', minHeight: minHeight || 'auto' }}
    >
      {content}
    </div>
  )
}

export function ItemPrimary({ content }) {
  return (
    <ItemDefault
      color="primary"
      width="20%"
      minHeight="40px"
      content={content}
    />
  )
}

export function ItemPrimaryFit({ content }) {
  return <ItemDefault color="primary" content={content} />
}

export function ItemSecondary({ content }) {
  return (
    <ItemDefault color="info" width="12%" minHeight="40px" content={content} />
  )
}

export function ItemSecondaryFit({ content }) {
  return <ItemDefault color="info" content={content} />
}

export function DefaultRow() {
  return (
    <>
      <ItemPrimaryFit content="Flex item 1" />
      <ItemSecondaryFit content="Flex item 2" />
      <ItemPrimaryFit content="Flex item 3" />
      <ItemSecondaryFit content="..." />
    </>
  )
}

Clases para manejar flex items

## Uso básico

Para poder usar flex items usar la clase `is-flex`

<PreviewElement>
  <div className="is-flex is-color-white is-gap-3">
    <DefaultRow />
  </div>
</PreviewElement>

```html
<div class="is-flex is-gap-3">
  <div>Flex item 1</div>
  <div>Flex item 2</div>
  <div>Flex item 3</div>
  <div>...</div>
</div>
```

## Flex direction

### Row

Usa `is-flex-row` para configurar la dirección horizontal

<PreviewElement>
  <div className="is-flex is-flex-row is-color-white is-gap-3">
    <DefaultRow />
  </div>
</PreviewElement>

:::tip

Por defecto usando solo `is-flex` ya está configurado como flex row

:::

### Column

Usa `is-flex-column` para configurar la dirección vertical

<PreviewElement>
  <div className="is-flex is-flex-column is-color-white is-gap-3">
    <DefaultRow />
  </div>
</PreviewElement>

```html
<div class="is-flex is-flex-column is-gap-3">
  <div>Flex item 1</div>
  <div>Flex item 2</div>
  <div>Flex item 3</div>
  <div>...</div>
</div>
```

## Gap

Usa `is-gap-{size}` para agregar espacio entre los elementos flexibles. El size es un valor entre `0` a `6`

## Justify content

| Clase                                                   | Propiedad                        |
| ------------------------------------------------------- | -------------------------------- |
| <CodeBlock>is-justify-content-flex-start</CodeBlock>    | `justify-content: flex-start`    |
| <CodeBlock>is-justify-content-flex-end</CodeBlock>      | `justify-content: flex-end`      |
| <CodeBlock>is-justify-content-end</CodeBlock>           | `justify-content: center`        |
| <CodeBlock>is-justify-content-space-between</CodeBlock> | `justify-content: space-between` |
| <CodeBlock>is-justify-content-space-around</CodeBlock>  | `justify-content: space-around`  |
| <CodeBlock>is-justify-content-space-evenly</CodeBlock>  | `justify-content: space-evenly`  |

### Gráfica

## Align items

| Clase                                            | Propiedad                 |
| ------------------------------------------------ | ------------------------- |
| <CodeBlock>is-align-items-flex-start</CodeBlock> | `align-items: flex-start` |
| <CodeBlock>is-align-items-flex-end</CodeBlock>   | `align-items: flex-end`   |
| <CodeBlock>is-align-items-center</CodeBlock>     | `align-items: center`     |
| <CodeBlock>is-align-items-stretch</CodeBlock>    | `align-items: stretch`    |
| <CodeBlock>is-align-items-baseline</CodeBlock>   | `align-items: baseline`   |

## Align content

:::info

Es útil cuando se trabaja con contenedores flexibles que tienen múltiples líneas de elementos flexibles (es decir, cuando `flex-wrap` está configurado en `wrap` o `wrap-reverse`).

:::

| Clase                                                 | Propiedad                      |
| ----------------------------------------------------- | ------------------------------ |
| <CodeBlock>is-align-content-flex-start</CodeBlock>    | `align-content: flex-start`    |
| <CodeBlock>is-align-content-flex-end</CodeBlock>      | `align-content: flex-end`      |
| <CodeBlock>is-align-content-center</CodeBlock>        | `align-content: center`        |
| <CodeBlock>is-align-content-space-between</CodeBlock> | `align-content: space-between` |
| <CodeBlock>is-align-content-space-around</CodeBlock>  | `align-content: space-around`  |
| <CodeBlock>is-align-content-space-evenly</CodeBlock>  | `align-content: space-evenly`  |
| <CodeBlock>is-align-content-stretch</CodeBlock>       | `align-content: stretch`       |

### Gráfica

export function FlexAlignContentRow({ title, className }) {

      </div>
