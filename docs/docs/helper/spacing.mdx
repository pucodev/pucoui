# Spacing

Configure the spacing between elements in your application.

:::info

To see the available sizes, visit the [customize spacing documentation](../customize/spacing).

:::

## Paddings and Margins

Using the values from the table above, you can add **padding** and **margins** using the `p*` and `m*` classes, respectively.

Additionally, you can customize them with the following directions:

| Class | Direction      |
| ----- | -------------- |
| `*t`  | top            |
| `*r`  | right          |
| `*b`  | bottom         |
| `*l`  | left           |
| `*x`  | left and right |
| `*y`  | top and bottom |

Next, you must add the spacing size, which can be from `0` to `7`.

### Examples

| Example | Style                                                                  |
| ------- | ---------------------------------------------------------------------- |
| `pt-0`  | <code>padding-top: {spaces[0]}rem </code>                              |
| `mb-3`  | <code>margin-bottom: {spaces[3]}rem</code>                             |
| `mx-2`  | <code>margin-left: {spaces[2]}rem; margin-right: {spaces[2]}rem</code> |

### Additional

You can also use the `*auto` attributes, which will set the **padding** or **margin** to `auto`.

#### Additional Examples

- `px-auto`
- `mx-auto`
