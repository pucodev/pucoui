### Como funciona

<details>
  <summary>Como functiona</summary>

1. Actualizamos las variables según el estilo de la página

<CodeBlock language="html">{TinyfloraTheme}</CodeBlock>

2. Instalamos fuentes, para este caso vamos a usar la fuente `Lato` desde [Google Fonts](https://fonts.google.com/specimen/Lato)

3. Agregamos la fuente al estilo del proyecto

<CodeBlock language="html">{TinyfloraFont}</CodeBlock>

4. Creamos clases propias del proyecto

<CodeBlock language="html">{TinyfloraClass}</CodeBlock>

5. La imágen que se muestra al lado derecho solo se debe mostrar cuando la pantalla es mayor a `md`, para lograr esto vamos a agregarle las clases `is-hidden md:is-flex` ocultando el elemento por defecto y volviendolo `flex` cuando la pantalla es mayor a `md`

6. El contenedor principal que tiene el formulario debe ser también responsive, tomando todo el ancho en pantallas pequeñas y una proporcion de `5/12` cuando la pantalla es mayor a `md`. Para esto vamos a agregarle al contenedor padre la clase `is-grid` y al contenedor del formulario las clases `is-col-12 md:is-col-5`

</details>
